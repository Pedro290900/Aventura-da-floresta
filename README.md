# Aventura-da-floresta
Jogo de plataforma 2D em HTML, CSS e JavaScript puro. Não precisa instalar bibliotecas.

## Controles
- PC: setas ou A/D para andar; Espaço, W ou seta para cima para pular.
- Celular: use os botões na parte inferior.
- Colete moedas, pule sobre os monstrinhos e alcance a bandeira.
